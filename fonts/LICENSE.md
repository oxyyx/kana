# Fonts

The `.woff2` files in this folder are subsets of fonts from Google Fonts, reduced to only the kana characters the app uses. They are **not** covered by the MIT license of this project. Each font is licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), and its full license text and copyright notice are in the matching `OFL-*.txt` file.

| File               | Font            | License text          | Source |
|--------------------|-----------------|-----------------------|--------|
| `textbook.woff2`    | Klee One        | `OFL-textbook.txt`    | https://fonts.google.com/specimen/Klee+One |
| `gothic.woff2`      | Noto Sans JP    | `OFL-gothic.txt`      | https://fonts.google.com/specimen/Noto+Sans+JP |
| `mincho.woff2`      | Shippori Mincho | `OFL-mincho.txt`      | https://fonts.google.com/specimen/Shippori+Mincho |
| `rounded.woff2`     | Zen Maru Gothic | `OFL-rounded.txt`     | https://fonts.google.com/specimen/Zen+Maru+Gothic |
| `calligraphy.woff2` | Yuji Syuku      | `OFL-calligraphy.txt` | https://fonts.google.com/specimen/Yuji+Syuku |
| `handwriting.woff2` | Yomogi          | `OFL-handwriting.txt` | https://fonts.google.com/specimen/Yomogi |
| `pixel.woff2`       | DotGothic16     | `OFL-pixel.txt`       | https://fonts.google.com/specimen/DotGothic16 |

The subsets were generated with the Google Fonts API (`text=` parameter). Noto Sans JP has the Reserved Font Name "Source"; the subset does not use that name.
